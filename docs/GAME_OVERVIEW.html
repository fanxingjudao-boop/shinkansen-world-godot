🚄 しんかんせんワールド

いまある「きのう(機能)」と「あそびの ながれ(フロー)」を、むずかしい言葉をかみ砕いて まとめたガイドです。

バージョン v0.55.0 / 2026-06-06 時点
① これは どんなゲーム? ② あそびの ながれ ③ 機能ぜんぶ ④ 7つの 別世界 ⑤ 遊び心(小ネタ) ⑥ 専門用語じてん ⑦ ファイルの地図 ⑧ 安全と配信

① これは どんなゲーム?

3〜7さいの お子さん・お孫さんが iPad で あそぶ、3D の オープンワールド(広い世界を じゆうに 歩ける) 電車ゲームです。 こわい敵・失敗・ゲームオーバー・制限時間は いっさい ありません。 「あつめる・出会う・のる・さがす・行ってみる」を じぶんのペースで たのしみます。

こわくない ひらがな・カタカナだけ 失敗なし 大きなボタン いつでも「やったね!」

② あそびの ながれ(フロー)

タイトルから あそぶまでの 大きな流れです。どこから やっても OK。順番に やる必要はありません。

1
タイトルで「はじめる」をタップ
音が鳴る準備が ここで ととのいます(iPad は「画面を さわってから」でないと音が出せないため)。最初の ミッションも やさしく お知らせ。
▼
2
歩いて 世界を たんけん
画面左の 十字ボタン(または キーボード)で 移動。カメラ ◀▶ で 見る向きを かえられます。山・湖・川・草原・街・お城が あります。
▼
3
あつめる・出会う
ほしを ひろう、どうぶつと なかよしに なる(8しゅるい)、駅を 見つける(6つ)。集めると「ずかん(図鑑)」が うまっていきます。
▼
4
電車に のる → うんてん → 各地へ
電車に ちかづいて「のる」。「ながめ」で 見る場所を かえ(やね/うんてんせき/まどぎわ)、「うんてん」で じぶんで ゴー/とまれ。 分かれ道で「みずうみ・やま・まち・おしろ」を えらぶと、その場所へ 走っていきます。v0.55.0
▼
5
「どこへ いく?」で 別世界へ
地上の メニューから、つき・そら・うみ・おかし・きょうりゅう・ゆき・ぎんが の 7つの世界へ ひとタップで 行けます(乗り物が 自動で 案内)。
▼
6
遊び心(小ネタ)で あそぶ
「てをふる」と みんなが 応える、かくれんぼ動物を さがす、楽器を ならす、たたくと 反応… 世界の あちこちに しかけが あります。
▼
7
ごほうび・ミッションで 達成感
ほしが たまると お祝い、なかよし動物が プレゼント、げんきが たまると 少し はやく 歩ける。ミッションは やさしく、達成すると「やったね!」。
💾 進み具合は 自動で セーブされます。次に ひらいたとき 続きから あそべます(数字だけを 保存。名前や 個人情報は いっさい 保存しません)。

⑥ 専門用語じてん(かみ砕いて)

コードや 引き継ぎ資料に 出てくる むずかしい言葉を、ふだんの 言葉で 説明します。

Godot(ゴドー)ゲームエンジン
ゲームを 作るための 無料ソフト。このゲームの 土台です。
GDScriptプログラム言語
Godot 用の プログラム言語。Python に 似ていて 読みやすい。コードの中身は これで 書かれています。
ノード / シーンNode / Scene
ノード=ゲームの 部品 ひとつ(キャラ・カメラ・電車など)。シーン=部品を 組み合わせた かたまり(=設計図)。世界は ノードの 木(ツリー)で できています。
Main.tscnメインシーン
世界ぜんぶが のっている いちばん上の 設計図ファイル。最近の 追加機能は、この ファイルを 書きかえずに(壊さないように)プログラムから 後づけしています。
_spawn_extra / 寄生方式parasitic spawn
設計図(Main.tscn)を いじらずに、ゲーム起動時に プログラムで 小さな機能を 後から くっつけるやり方。遊び心や 銀河鉄道は これで 足しています(設計図を 壊すリスクが 小さい)。
Path3D / PathFollow / Curve3D線路のしくみ
Curve3D=曲がった 一本の 線(線路の 中心線)。Path3D=その線を 世界に 置いたもの。PathFollow=その線の上を 進む 台車。電車は この上を すべって 走ります。
分岐スワップ / フェード遷移branch swap / fade
運転中に 別の線路へ 乗り換えるとき、画面を 一瞬 ふわっと 暗くして(=フェード)、その間に 電車を 別の線路へ こっそり 移します。だから 離れた場所どうしでも 瞬間移動が 見えません。乗り換え先に いた電車とは 入れ替えるので、線路が 二重に なりません。
MultiMesh / ArrayMeshえがく しくみ
MultiMesh=同じ形を たくさん(草・枕木・星)まとめて 一度に えがくしくみ。ArrayMesh=点をつないで 自分で 形を作るメッシュ(レール・道路・バラストなど)。どちらも「重くならない ように まとめる」ための 工夫です。
draw call(ドローコール)えがく回数
画面に 1つ えがくよう 命令する 回数。多いほど 重くなる。だから 上の MultiMesh などで 回数を 減らして、iPad でも なめらかに 動くようにしています。
距離カリングdistance culling
遠くて 見えない/気づかれない ものは えがくのを やめること(例:遠い電車の 車輪は 回さない)。軽くするための 工夫です。
パーティクル / TweenGPUParticles / Tween
パーティクル=雪・泡・キラキラ など 小さな粒の 演出。Tween(トゥイーン)=「だんだん 大きく」「ぴょこっと」など なめらかな 動きを つけるしくみ。
Compatibility レンダラーえがく方式
Web(ブラウザ)で 動かすための えがき方。最新の 重い効果は 使えない代わりに、iPad の Safari でも 動きます。だから「写実」より「光って はじけて ふわふわ」で かわいく 作っています。
PWA / Web Export配信のかたち
Web Export=ゲームを ブラウザで 動く形に 書き出すこと。PWA=その Web を アプリのように ホーム画面に 置いて 全画面で 遊べる しくみ。インストール不要・URL を 送るだけ。
再エクスポートre-export
プログラムを 直したら、ブラウザ用の ファイル(export/web)を 作りなおすこと。これを して はじめて、直した内容が ライブ(本番サイト)に 出ます。
Vercel(ヴァーセル)置き場所
ゲームを 置いて 公開している サービス。GitHub に push すると、自動で 本番サイトが 更新されます。
セーブ(user://)進捗の保存
あそんだ 記録(ほしの数・なかよし・行った場所など 数字だけ)を ブラウザの中に 保存。次に ひらくと 続きから。名前・年齢などは 保存しません。

⑦ ファイルの地図(ざっくり)

「この機能は どこ?」の めやす。すべて scripts/ の下に あります。

ファイルやくわり
main.gd入口。起動時に 遊び心・銀河鉄道などを 後づけ(_spawn_extra)。
entities/player.gd主人公の 動き・手振り・歩行アニメ。
entities/train.gd電車の 見た目・走行・運転・窓の乗客。
world/railway.gd線路網(レール・枕木・バラスト)を 作る。
world/route_data.gdどの線路が どこを通るか・分岐の つなぎ方。
world/ride_controller.gdのる/おりる・視点・運転・分岐2択。
world/town.gd街・道路・踏切の 配置。
world/crossing.gd踏切 1つ分(遮断機・灯・音)。
world/game_state.gd進捗の 一元管理(ほし・なかよし・行った場所)。
world/save_system.gd進捗の 保存/読込。
world/*_land.gd / moon_trip / submarine / sky_castle / ginga_railway7つの 別世界。
world/instruments / hide_and_seek / magic_steps / interactables / rare_train …遊び心の 小ネタ。
ui/touch_hud.gd / book.gd / world_select.gd / settings.gd画面の ボタン・図鑑・おでかけメニュー・親モード。
dev/auto_capture.gd開発用:自動で スクショを撮って 見た目を 確認する。
📄 もっと くわしい 経緯・判断は docs/HANDOFF.md、変更の 履歴は changelog.md、小ネタの 仕様は docs/PLAYFUL_DETAILS.md に あります。

⑧ 安全と配信(子供向けの まもりごと)

  • 個人情報を いっさい 集めない・保存しない(セーブは 数字だけ)。
  • 外部への 通信なし(広告・アクセス解析・SNS連携は 入れない)。フォントなども ゲームに 同梱。
  • 入力欄・外部リンクなし(子供が うっかり 外に 出る経路を 作らない)。
  • 検索に 載せない(noindex / robots.txt)。セキュリティの 設定(CSP など)を 維持。
  • 怖くない・失敗なし・時間制限なし。漢字を 使わず ひらがな・カタカナだけ。

配信の 流れ:プログラムを 直す → 再エクスポート(ブラウザ用に 作りなおす)→ GitHub に push → Vercel が 自動で 本番サイトを 更新 → iPad の Safari で あそぶ。
